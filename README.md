<h2>Key learning<h2>
  <p>기본적인 form태그 활용 방법을 익혔습니다.</p>
  <p>form태그 사용을 위해서 필요한 요소들을 어떻게 활용하는지 배웠습니다.</p>
  <p>javascript를 통해서 점검validation하는 방법도 익혔습니다.</p>

  <h2>Form elements</h2>
  <p>label: 입력창의 이름을 표시하는 태그입니다. for, id를 짝을 맞추면 이름만 클릭해도 입력할 수 있습니다.</p>
  <p>type: type을 통해서 어떤 종류의 입력을 받을 건지 그 용도를 설정할 수 있습니다.</p>
  <p>text: 문자열을 입력받을 때 사용할 수 있습니다.</p>
  <p>email: 이메일 주소를 입력받을 때 사용합니다.</p>
  <p>date: 날짜를 입력받을 때 사용할 수 있습니다.</p>
  <p>checkbox: 여러 항목 중 복수 선택 및 해제를 받을 때 사용합니다.</p>
  <p>radio: 여러 옵션 중 하나만 선택받을 때 사용할 수 있습니다.</p>
  <p>select, potion: 미리 정한 목록에서 하나를 고르도록 할 때 사용합니다.</p>
  <p>textarea: 그냥 text와 달리 여러 줄의 긴 문장을 입력받을 때 사용합니다.</p>
  <p>required: 필수로 입력받아야 하는 항목들을 지정할 때 사용할 수 있습니다.</p>
  <p>minlength: 입력받을 문자열의 최소 길이를 지정할 때 사용합니다.</p>
  <p>placeholder: 입력 창이 비어있을 때 예시 문구를 보여줍니다.</p>

  <h2>HTML vs CSS</h2>
  <p>HTML은 정말 순수하게 안의 내용과 구조만 구분해놓았습니다.</p>
  <p>css에서는 문서 배치와 간단한 디자인을 추가했습니다.</p>
  
  <h2>validation & JS</h2>
  <p>필수로 입력받아야 하는 항목들은 필수로 입력받도록 하였고 그 중에서도 특별한 글자 수가 요구되는 cvv나, expirartion 같은 것들은 최소 몇 글자 이상 입력받을 수 있도록 하였습니다.</p>
  <P>email은 정해진 형식을 지켜서 입력받도록 하였습니다. 이러한 것들이 제대로 입력이 되지 않으면 어떤 것이 제대로 입력이 되지 않았는지</P>
  <p>확인할 수 있도록 팝업창이 뜨고 submit할 수 없도록 하였습니다.</p>

  <h2>problem & solution</h2>
  <p>이번 과제를 하면서 확실히 이제 html과 css는 나름 익숙해져서 쉬웠지만 form태그의 다양한 attribute들을 어떻게 사용하는지 몰라서
  w3schools를 통해 익혔습니다. 또 javascript부분은 저번 주에 ai에 전적으로 의존했었어서 뭐가 뭔지 잘 몰랐는데
  이번 과제를 통해서 ai와 같이 공부하면서 form에 사용되는 부분 만큼은 확실 익혔습니다.</p>

    여러 개를 틀려도 위에서부터 봤을 때 가장 먼저 틀린 거 하나만 출력이 되던데 전체적으로 보고 틀린 것들을 전부 말해주는 팝업창이 뜨게 할 수는 없는 건지 궁금합니다.
